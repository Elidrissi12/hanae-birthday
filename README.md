# Hanae — cadeau d’Amine

Site frontend statique en darija : anniversaire, quiz et lettre.

## Aperçu local
Ouvrir index.html dans un navigateur, ou lancer :

    python -m http.server 4173

Puis ouvrir http://localhost:4173.

## Vercel
Importer ce dépôt GitHub. Choisir Framework Preset : Other ; Root Directory : ./ ; Build Command : vide ; Output Directory : . (racine).
Aucun backend, build ni variable d’environnement requis.

## Modifier
- index.html : contenu et lettre.
- style.css : apparence.
- app.js : quiz et animations.

Les réponses ne sont pas enregistrées. Google Fonts est facultatif, avec des polices de secours.
